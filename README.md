# Magento-Plugin-New

This is the default Magento integration for Printess.

It covers the most common use cases for setting up a store in Magento and utilising Printess for customisation.

## How to use this Plugin

There is an in depth guide in the [Printess Knowledge Base](https://www.printess.com/kb.html#integrations/magento.html).
If you run into any trouble using the guide, please reach out to us!

## I'm missing an important feature

Feel free to reach out to us through our support chat over at [our website](https://www.printess.com/)!

If you can code and have an idea how to implement the feature you need, feel free to fork this repository and/or open a pull request with your suggested changes.
Should we also like your idea and implementation, we will merge your changes and be forever thankful!

## How did you make such a cool plugin?

Actually, a lot of this plugin was written by AI, utilising our [Printess skills](https://github.com/PrintessEditor/printess-skills).
If you need a custom Printess implementation and you don't want to use this default plugin, you might want to use these AI skills as a base for your project.
